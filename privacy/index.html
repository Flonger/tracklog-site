一、适用范围与版本

本政策适用于移动应用「轨迹」（iOS Bundle ID com.tracklog.application（Android：com.tracklog.tracklog），版本 1.0.0）。本应用面向铁路模型收藏者，在本机登记车辆、养护与运转信息，并提供随包图鉴。

本应用没有账号体系，不提供注册或登录，也不提供云同步。你与本应用相关的隐私问题，可通过本页末尾的联系邮箱与我们联系。

二、我们如何处理信息

本应用处理信息的方式分三类，说明如下，避免笼统表述：

  1. 车库与收藏内容：仅保存在你使用的这台设备本地，我们不会将其上传到自有服务器。
  2. 图鉴封面显示：当你打开带封面的图鉴条目时，设备会向该封面所在的图床发起一次图片请求，用于在本机显示封面。
  3. 崩溃分析：本应用接入腾讯 Bugly SDK，用于采集崩溃与异常相关信息，以便定位和修复问题。该项不是广告投放，也不是用户画像营销。

我们不会把你的车库内容（车号、涂装、买价、本地照片等）出售或提供给广告商，也不会将其交给第三方人工智能服务用于训练。

三、本机数据

你写入的车号、涂装、比例、养护、运转、买价，以及你选进车库的照片，保存在这台设备的本地数据库与应用目录中。卸载应用后，这些内容随应用数据一并删除。我们没有服务器侧的车库副本，无法代为恢复。

买价未填写时，界面显示「未标价」。该数字不会因车库功能被上传。

导出 JSON 只会写成你自己选择的文件；应用不会在导出流程中代你把车库内容发往第三方。

四、第三方 SDK 与外部请求

4.1 腾讯 Bugly SDK（崩溃分析）

SDK 名称腾讯 Bugly SDK（崩溃分析）
服务提供方深圳市腾讯计算机系统有限公司
使用目的采集崩溃 / 异常日志，定位与修复稳定性问题；不用于广告投放或画像营销
处理的信息类型日志信息（含崩溃堆栈、相关运行日志）、设备标识（Android 端 Android ID；iOS 端 IDFV）、联网信息、系统名称与版本、国家码；以及崩溃排查所需的设备型号、操作系统版本等运行环境信息。具体以腾讯 Bugly 官方隐私声明所列为准
存储与处理境内存储；通过去标识化等技术手段处理，并采用加密等安全措施传输与存储（详见官方声明）
官方说明 Bugly SDK 隐私保护声明（PDF）
腾讯 Bugly 相关隐私保护文档

Bugly 处理的是崩溃与运行诊断相关信息，不包含你的车库条目正文（如车号、买价清单）作为业务上传内容。关于 Bugly 收集范围的完整说明，以腾讯上述官方文件为准。

4.2 图鉴封面图床请求

打开带封面的图鉴时，设备会向该图片所在图床请求这一张图。Kato、Hpoi 等来源的封面可能按对方官网要求附带 Referer，否则图片可能无法显示。图床运营方可看到该次请求的网络地址等信息，但看不到你车库里的车号与买价。

五、权限与网络

本应用不申请定位、通讯录、电话、短信权限。

可选使用系统相册挑选车辆照片；照片仅复制到本机应用目录，不会作为车库内容上传。拒绝相册权限时，其它功能仍可使用。

正式包声明网络访问（如 Android INTERNET），用于：

  • 图鉴封面图请求；
  • 腾讯 Bugly 的崩溃 / 异常信息上报。

六、儿童个人信息

本应用不以儿童为主要服务对象，不会主动向未满 14 周岁的儿童收集其个人信息。若监护人认为我们在不知情的情况下处理了儿童相关信息，请通过下方邮箱联系，我们将在核实后尽快删除或停止相关处理（法律另有规定的除外）。

七、你的权利与联系方式

因本应用无账号，本地车库数据由你在本机直接管理（编辑、删除、导出或卸载清除）。

就隐私政策、个人信息处理，或希望我们就 Bugly 相关诊断数据协助主张查询、删除等合理请求，请发信至：

xue@flonger.com

我们将在核实身份与请求内容后尽快回复。涉及腾讯 Bugly 直接处理的数据，我们也可能依据官方渠道协助你向腾讯提出请求。
